# Software Engineering Academy

A standalone, responsive Software Engineering learning website with 100 class-wise topics, detailed learning notes, a visual diagram library, six applied case studies, topic quizzes, interview questions, books and online references.

## Features
- 100-class curriculum with class completion tracking and search
- Detailed notes, principles, artifacts, application guidance, review checklists and common pitfalls
- Embedded SVG diagrams for software lifecycle, process models, UML, data modelling, architecture, testing, quality and project delivery
- Case studies: Campus Management, Hospital Appointment Portal, Online Bookstore, Library Management, Food Delivery and Online Examination
- Topic quizzes, 20-question assessment, interview questions and academic profile
- No programming examples or syntax sections; content focuses on software engineering concepts and models

## Publish on GitHub Pages
1. Upload `index.html`, `README.md`, and `.nojekyll` to the root of a GitHub repository.
2. Open **Settings → Pages**.
3. Choose **Deploy from a branch**, select `main` and `/(root)`, then save.

The site is self-contained; diagrams are embedded in the HTML.
